# Telegram NFT Upgrade Bot

Работает без пользовательской авторизации и без Telethon. Публично парсит `t.me/nft`, автоматически получает список всех коллекций с Fragment и отправляет уведомления через Bot API.

## Inline-меню

`🎁 Последний улучшенный подарок` → выбор коллекции → выбор фона → последний известный номер, ссылка, владелец и атрибуты.

При первом открытии коллекции бот сканирует последние `BACKGROUND_SCAN_DEPTH` подарков, чтобы построить список фонов и найти последний номер для каждого фона.

## Запуск

1. Создайте бота через `@BotFather`.
2. Отправьте ему `/start`.
3. Узнайте свой `chat_id` и заполните `.env`.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

На первом цикле бот запоминает последние номера без старых уведомлений. Затем сообщает обо всех новых номерах во всех обнаруженных коллекциях.

Список коллекций обновляется с `https://fragment.com/gifts`; если Fragment временно недоступен, используется резервный публичный список GitHub.
